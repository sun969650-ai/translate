使用步骤

半分钟上线

无需构建、无需依赖，加载即用。

  1. 1

    加载扩展

    打开 chrome://extensions/，开启「开发者模式」，点击「加载已解压的扩展程序」并选择项目目录。

  2. 2

    填写配置

    点击工具栏图标，在弹窗中填入 BaseUrl、API Key 与模型名称，点击「测试连接」验证。

  3. 3

    开始使用

    打开任意网页，点击「翻译本页」；选中文字即可划词翻译；点击「网页总结」提炼要点。

常见问题

你可能想知道的

支持哪些浏览器？

基于 Chrome Manifest V3，Chrome 与 Edge（Chromium 内核）均可直接使用；在 Edge 中需在扩展管理页开启「允许来自其他商店的扩展」。

支持哪些模型服务？

任何兼容 OpenAI Chat Completions 协议的服务都可以，例如 DeepSeek、OpenAI、通义千问、智谱、本地 Ollama 等，只需填写对应的 BaseUrl、API Key 与模型名。

翻译整页会不会破坏网页排版？

不会。插件只替换文本节点内容，不改动标签结构与样式，并保留首尾空格、URL、邮箱、代码标识符与占位符；点击「恢复原文」可立即还原。

API Key 安全吗？

配置保存在浏览器本地存储（chrome.storage.local），不会上传到任何第三方服务器，请求只发往你自己填写的接口地址。

大页面翻译会花很多钱吗？

插件采用分批并发 + 结果缓存，重复内容只请求一次；仅翻译页面上可见的文字，跳过代码块、输入框与不可见元素。

让阅读、翻译、总结都不再费时间

开源免费，配置自己的 API Key 即可长期使用。
